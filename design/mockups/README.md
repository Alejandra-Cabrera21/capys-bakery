# Mockups

Diseño de referencia de las 8 pantallas principales del sitio (Inicio, Catálogo, Detalle con configurador, Carrito, Nosotros, Eventos y Catering, Blog, Contacto).

- `capys-mockups.html` — Las 8 pantallas en un solo archivo.
- `capys-mockups-parte1.html` / `parte2.html` — Mismas pantallas divididas en dos archivos (4 cada uno), pensado para importarlas a Figma con el plugin html.to.design sin que se compriman.
- `*.png` — Captura de cada pantalla en alta resolución.
