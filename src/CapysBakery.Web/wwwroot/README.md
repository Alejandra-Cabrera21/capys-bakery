# wwwroot

Archivos estáticos servidos directamente: `css/`, `js/`, `img/`.

**Bootstrap** se agrega aquí (vía LibMan, `dotnet new mvc` ya lo incluye por defecto, o CDN) como base de estilos. Sobre esa base se aplica la identidad visual definida en los mockups: paleta cálida (crema `#FBF1E4`, dorado `#C9982E`, ciruela `#7C2B3B`), tipografía *Fraunces* para títulos y *Work Sans* para texto general.
